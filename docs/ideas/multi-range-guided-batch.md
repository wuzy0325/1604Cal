# 多量程向导式分批计量

## 问题陈述

**HMW**：如何让一线计量操作员在 16 通道 / 多量程压力传感器 + **每批需换标准器**的约束下，连贯完成分批计量，用核对码防遗漏，最终自动合并为一份报告？

## 推荐方向

**纯向导式分批**——在现有 `MeasurementView` 上增加分批模式，不引入"总任务/子任务"等新概念。

核心流程：
1. 操作员在页面上录入 16 个通道的量程（数值 + 单位下拉）
2. 系统自动按量程分组，显示"本次共 N 批"
3. 逐批引导：弹窗提示"请切换到 X MPa 标准器" → **核对码输入**（必须输入当前批次量程值，如 `10`，与标准器标识核对） → 解锁加压序列
4. 每批加压序列自动连续执行，操作员可暂停/中止
5. 全部批次完成后，自动合并为一份报告，按批次分段

关键设计决策：
- **核对码 = 当前批次量程值**（精确匹配），不是任意输入。操作员必须看了标准器上的量程标识才能输入正确值。
- **不引入"总任务"概念**，流程本身就是线性的——换标准器这个物理约束决定了不能并行。

## 关键假设

- [ ] 操作员能准确录入 16 个通道的量程——输入错误会导致分组错误，但报告的录入记录可追溯复核
- [ ] 核对码（量程值精确匹配）能有效防止"肌肉记忆跳过"——如果操作员不核对标准器标识就输入，会被拒绝。需在实际使用中观察操作员是否会在标准器上贴大字标识辅助核对
- [ ] 现有加压序列 API 可直接复用，无需为分批模式重新设计——分批只是切换通道子集，加压逻辑不变

## MVP 范围

**做**：
- 16 通道量程录入面板（数值 + 单位下拉，默认 MPa）
- 自动按量程分组（同量程通道默认选中，可手动调整）
- 同批量程一致性校验（实时警告 + 二次确认，允许继续）
- 核对码弹窗：提示切换标准器 + 输入量程值确认，**量程值精确匹配才通过**
- 逐批加压序列（复用现有加压流程）
- 全部批次完成后自动合并报告（按批次分段，标注通道列表、量程、加压点结果）

**不做**：
- 总任务/子任务概念
- 跨批次并行加压
- 预存台账 / 预定义方案模板
- 通道跳过标记（一期不做，所有 16 通道必须参与）

## 不做清单（及原因）

- **"总任务"概念** — 换标准器是线性的，不需要并行编排。全局进度用"第 N/共 M 批"即可。
- **预定义标定方案模板** — 与意图文档"量程现场录入"决策一致，不引入模板管理复杂度。
- **通道跳过标记** — 一期先做全量，后续迭代再加。
- **自动切换标准器** — 需要硬件改造，不在软件范围内。
- **跨任务批合并** — 合并只在一个 session 内做。

## 已确认决策

- **批次回退**：允许回退重跑。操作员可以回到任意已完成的批次，重新执行加压序列（覆盖原结果）。
- **断点恢复**：不保留。页面刷新或关闭后从头开始。回退重跑能力已覆盖恢复需求——操作员重新进入后录入量程，重跑丢失的批次即可。
